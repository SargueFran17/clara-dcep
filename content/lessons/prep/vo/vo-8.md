## Objectives

- Use **natural verb + noun combinations** (collocations) that colleagues use every day.
- Sound professional in briefings, handovers and on the radio.
- Avoid literal translations from Spanish.

## Explanation

### Collocations to learn as blocks

| Collocation | Meaning / use |
|---|---|
| **attend** a call / an incident / a scene | go to (not *assist*!) |
| **respond to** a call | react and go |
| **be deployed** to | be sent to |
| **make** an arrest | arrest someone |
| **take** a statement / a first account | record what someone says |
| **carry out / conduct** a search / enquiries | do |
| **issue** a warning / a notice / a ticket | give formally |
| **secure** a scene / evidence | protect |
| **preserve** evidence / life | keep safe |
| **seize** property / a vehicle | take legally |
| **liaise with** another agency / team | work and communicate with |
| **update** the log / the victim / the OIC | give the latest information |
| **brief / debrief** | give information before / review after |
| **hand over** a job / a prisoner | pass to another officer |
| **book on / book off** (duty) | start / finish shift |
| **flag up** a concern / a risk | point out |
| **escalate** to a supervisor | pass up for a decision |
| **risk-assess** / **carry out a risk assessment** | assess risk |
| **raise** a concern / an intelligence report | create / report |

:::es
Aprende **bloques**: **attend** a call (acudir – ¡no *assist*!), **make** an arrest, **take** a statement, **carry out** enquiries, **issue** a warning, **secure** a scene, **preserve** evidence, **liaise with** (coordinarse con), **update** the log, **hand over**, **book on/off** (empezar/terminar turno), **flag up** (señalar), **escalate** (elevar al supervisor), **raise** a concern.
:::

### Briefing / handover language

- *"Quick **handover**: male in custody for burglary, **booked in** at 14:20, **relevant time** 13:55. **Outstanding** enquiries: CCTV from the Co-op and house-to-house. I've **flagged up** a safeguarding concern about the children. The victim's been **updated**."*
- *"Can you **chase up** the CCTV?"* (follow up urgently)
- *"Who's **picking up** the job?"* (taking responsibility)

:::es
En traspasos: **outstanding enquiries** = gestiones pendientes; **chase up** = reclamar/seguir; **pick up the job** = hacerse cargo.
:::

## Police scenarios

> *I **booked on** at 07:00 and was **deployed** to a report of a burglary. I **attended**, **secured the scene**, **took a first account** from the victim and **liaised with** the CSI. I **updated the log** and **handed over** to CID at 11:00.*

## Common mistakes (Spanish speakers)

- ❌ *I assisted to the call* → ✅ *I **attended** the call*.
- ❌ *I did an arrest* → ✅ *I **made** an arrest*.
- ❌ *I made a search* → ✅ *I **carried out / conducted** a search*.
- ❌ *coordinate with* (OK) but **liaise with** is the police word.

## Summary

1. attend a call; make an arrest; take a statement.
2. carry out/conduct a search; issue a warning.
3. secure a scene; preserve evidence; seize property.
4. liaise with, update, hand over, escalate, flag up.
5. book on/off; outstanding enquiries; chase up.
